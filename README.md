# Bogan AI — Ваш персональный AI-ассистент

Современное веб-приложение для общения с искусственным интеллектом, построенное на стеке Flask + GPT-4o.

## 🚀 Основные возможности

- **Быстрый чат**: Общение с ИИ в реальном времени без перезагрузки страницы (AJAX).
- **История диалогов**: Все ваши чаты сохраняются, вы можете вернуться к ним в любое время.
- **Авторизация**: Личный кабинет с регистрацией и входом для защиты ваших данных.
- **Современный UI**: Адаптивный дизайн на Bootstrap 5 с темной боковой панелью и приятными градиентами.
- **Умные аватарки**: Уникальный визуальный стиль для ИИ и пользователя.
- **Индикатор печати**: Вы видите, когда ИИ готовит ответ.

## 🛠 Стек технологий

- **Backend**: Python, Flask, Flask-SQLAlchemy (ORM).
- **Frontend**: HTML5, CSS3, JavaScript (AJAX/Fetch API), Bootstrap 5.
- **Database**: SQLite.
- **AI**: Интеграция с GPT-4o через AgentPlatform API.

## 📦 Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Wwwixz/Bogan_AI.git
   cd Bogan_AI
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**:
   ```bash
   python main.py
   ```

4. **Откройте в браузере**:
   Перейдите по адресу `http://127.0.0.1:8086`
